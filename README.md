# Evan Ma

> Building auditable AI agent workflows and human-AI learning systems.
> 把 AI 协作从一次性聊天，变成可追踪、可复盘、可改进的工作系统。

I build **protocols, tools, and skills for trustworthy AI agent work**: task packets, work receipts, handoffs, operating memory, and human review boundaries.

My current center of gravity is **SACP**: a small, text-first protocol for making long-running agent work auditable.

```text
No receipt, no trust.
```

## Core System

These projects are meant to work together, not sit as isolated repositories.

```text
Human intent
  -> task contract
  -> agent work
  -> evidence receipt
  -> operating memory
  -> review and evolution
```

| Project | Role |
|---|---|
| [SACP](https://github.com/aDragon0707/sacp) | Audit protocol for long-horizon AI agent work |
| [Solo-AI-Company-OS](https://github.com/aDragon0707/Solo-AI-Company-OS) | Operating memory for decisions, worklogs, handoffs, and skills |
| [token-prompt-compiler](https://github.com/aDragon0707/token-prompt-compiler) | Pre-flight contract compiler for LLM and agent tasks |
| [Agent Flight Recorder](https://github.com/aDragon0707/audit-evolution-agent-flight-recorder) | Evidence loop for snapshots, evolution cards, and next-run bootstraps |

## What I Care About

## What I Am Building Toward

I use GitHub as a public lab for turning AI workflow experiments into clearer protocols, tools, demos, and reusable skills.

The long-term question:

```text
How can humans and AI systems work together in a way that is traceable,
reviewable, improvable, and aligned with human judgment?
```

中文说法更简单一点：

```text
不是让 AI 更会表演完成，而是让人能看见它到底做了什么。
```
